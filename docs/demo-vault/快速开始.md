# 快速开始

## 三种编辑模式

按 `Ctrl+E` 在 **源码 → 分屏 → 阅读** 之间循环切换。分屏模式下拖动中间分隔条可调整宽度，双击复位。

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+P` | 快速打开（文件名 / 别名搜索） |
| `Ctrl+Shift+F` | 全文搜索 |
| `Ctrl+N` | 新建笔记 |
| `Ctrl+D` | 打开 / 创建今日笔记 |
| `Ctrl+G` | 图谱视图 |
| `Ctrl+,` | 设置 |

## 建立你自己的库

一个本地文件夹就是一个知识库（vault）。右键文件树可以新建、重命名、删除笔记；删除会进系统回收站，不用担心误删。

粘贴图片时，EasyMD 自动把它存进 `assets/` 并插入嵌入语法。

参见 [[双向链接]] 了解如何把笔记连接起来。
