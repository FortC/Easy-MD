# 标签与属性

## YAML frontmatter

笔记顶部的 `---` 区块是 [YAML frontmatter](https://jekyllrb.com/docs/front-matter/)。在右侧栏「属性」面板里可以**可视化编辑**别名、标签和自定义字段，保存时直接写回文件头部。

## 正文标签

正文中任意位置写 `#标签` 即可打标签，支持多级：

#入门 #工具/Markdown #知识管理

左侧栏的标签树会汇总全库标签，点击即可筛选。
