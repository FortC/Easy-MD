# 欢迎使用 EasyMD

EasyMD 是一款**本地优先**的 Markdown 知识库：所有笔记都是磁盘上普通的 `.md` 文件，没有私有格式、没有账号、没有插件系统——你的数据永远属于你自己。

## 从这里开始

- [[快速开始]] —— 三种编辑模式与常用快捷键
- [[双向链接]] —— 用 `[[笔记]]` 把想法连成网络
- [[标签与属性]] —— frontmatter 可视化编辑
- [[知识图谱]] —— 看见笔记之间的关联
- [[云同步]] —— 可选的 MCP 云端备份

## 为什么选择 EasyMD

1. **磁盘文件是唯一真相源**，索引只是缓存，随时可以删除重建
2. **Rust 索引引擎**在后台解析双链 / 标签 / 标题，边写边更新
3. 界面克制干净，暗色亮色主题随系统切换

> 把任何一段文字变成知识，只需要一个 `[[链接]]`。

## 一段 Markdown 示例

```md
# 标题
**加粗**、*斜体*、~~删除线~~、`行内代码`
- [ ] 任务列表
- [x] 已完成
![[图片.png]]   嵌入图片
```
