# 双向链接

在任意笔记里输入 `[[`，补全列表会弹出。支持四种写法：

- `[[欢迎]]` —— 链接到一篇笔记
- `[[欢迎|首页]]` —— 使用别名显示
- `[[快速开始#三种编辑模式]]` —— 链接到某个标题

在链接前加感叹号 `![[欢迎]]`，可以把整篇笔记（或某个标题、某个块）**嵌入**当前位置。

## 反向链接

打开右侧栏的「反链」面板，可以看到**谁引用了当前笔记**，并跳转到对应位置。比如本篇笔记就被 [[欢迎]] 引用了。

配合 [[知识图谱]]，链接关系一目了然。
